# Welcome to LambdaGuide 🌈

Step-by-step tutorials for acquiring and processing hyperspectral CLEM (λ-scan) data:

- **Emission spectra → physiology**, analysed with [StellarStats](https://github.com/eSveeDee/StellarStats)
- **Excitation spectra → clade identification**, analysed with [PhytoSpectra](https://github.com/anogalesmoral/Phytospectra)

📖 Documentation: https://lambdaguide.github.io/

Part of the [TomoGuide](https://tomoguide.github.io/) family.
