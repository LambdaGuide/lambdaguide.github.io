# **Welcome to LambdaGuide 🌈**

Tutorials for acquiring and processing hyperspectral CLEM (λ-scan) data on cryo-fixed samples:

- **[Emission spectra → physiology]({{ '/03-emission-physiology/' | relative_url }})** — per-cell emission spectra and ratio metrics with [StellarStats](https://github.com/eSveeDee/StellarStats).
- **[Excitation spectra → clade identification]({{ '/04-excitation-clades/' | relative_url }})** — excitation fingerprints classified with [PhytoSpectra](https://github.com/anogalesmoral/Phytospectra).

New to spectral imaging? Start with [Some words about hyperspectral CLEM]({{ '/01-hyperspectral-clem/' | relative_url }}).

LambdaGuide is a sibling of [TomoGuide](https://tomoguide.github.io/), maintained by the [Cell Architecture Lab](https://www.cellarchlab.com/). Ideas, issues, corrections: [GitHub](https://github.com/LambdaGuide/LambdaGuide.github.io).
