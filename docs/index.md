# **Welcome to LambdaGuide 🌈**

This website serves as a resource and tutorial for the acquisition and analysis of hyperspectral correlative light and electron microscopy (hsCLEM) data. 
We offer an overview of various acquisition methods and considerations, sample data, tutorials for analysis, and reference spectra for clade identification.

[insert image]

### Start by selecting a topic from the sidebar!

You have multiple options to choose from! 
- To learn about data acquisition of single cell emission spectra (λ-scan), start here.
- To learn about the acquisition excitation spectra for clade identification, start here.
- For tutorials on analysis of hsCLEM data, see the StellarStats tutorial for emission spectra, and the PhytoSpectra tutorial for excitation spectra.


**New to spectral imaging?** Start with [An introduction to hyperspectral CLEM]({{ '/01-hyperspectral-clem/' | relative_url }}).

LambdaGuide is a sibling of [TomoGuide](https://tomoguide.github.io/), maintained by the [Cell Architecture Lab](https://www.cellarchlab.com/). Ideas, issues, corrections: [GitHub](https://github.com/LambdaGuide/LambdaGuide.github.io).
